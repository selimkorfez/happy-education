# Migration QA — public overview

Before release, editors should check migrated pages and articles for accurate content,
rights, links, redirects, language assignment, images, and author attribution. Publish an
expert byline only after the named person has approved it; otherwise omit the byline.

Detailed legacy account records and internal QA evidence are kept privately with authorised
project members. A fresh review is required before treating any historical QA result as current.
