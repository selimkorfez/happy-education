# Content migration — public overview

Legacy website content is classified for retention, rewrite, merge, or retirement before it
is imported into the new content model. Editors must review accuracy, rights, translations,
redirects, and attribution before publishing migrated material.

Raw account exports, credentials, incident evidence, and full operational backups belong in
the client's private storage. This public overview does not replace the owner-approved
migration plan or editorial sign-off.
