# Architecture — public overview

The rebuild is a Next.js application with a Sanity-backed content model. Public pages are
rendered by the application, while server routes handle integrations and validate incoming
requests. Locale-aware routing supports English and Turkish content.

Detailed system topology, integration configuration, and client operational decisions are
maintained with authorised project members outside this public repository. Consult the source
code and tests for implementation details that are appropriate to publish.
