# Legacy-site security handover

The existing production platform and email domain require a separate security review and
remediation plan. This rebuild does not secure systems that it has not replaced.

Detailed findings, affected components, account information, infrastructure details, and
verification evidence are intentionally omitted from this public repository. The site owner
and authorised administrators should use the private assessment, confirm the present state,
complete remediation, and record a new verification date. Do not infer current security status
from historical repository content.

If there is a suspected active incident, involve the owner and qualified incident responders
before making changes that might destroy evidence. Coordinate website, hosting, and email-domain
work independently of the rebuild's launch schedule.
