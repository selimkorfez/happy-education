# Migrated content bundle

Generated by `node scripts/migrate/extract.mjs` from the legacy WordPress export.

These are Sanity-shaped documents waiting to be imported. Until a Sanity project
exists they are also read directly by `src/lib/content/local-source.ts`, so the site
renders and the corpus can be reviewed on the real templates before it is committed.

**Sanity always takes precedence.** The moment `NEXT_PUBLIC_SANITY_PROJECT_ID` is
set, this directory is never read.

To import: `node scripts/migrate/import.mjs --commit` (needs `SANITY_API_WRITE_TOKEN`).
Once the import is verified, delete this directory. Nothing else depends on it.

300 documents. 300 carry an editorial flag; 255 contain time-sensitive claims that
must be re-verified before publication. See `docs/MIGRATION_QA.md`.
